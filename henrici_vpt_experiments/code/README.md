# Henrici departure vs Valid Prediction Time — Lorenz-63 reservoir experiments

Experiments demonstrating that reservoir computer matrices with a **larger
Henrici departure** (larger departure from normality) tend to produce
**shorter valid prediction times (VPT)** on the Lorenz-63 system, across
several reservoir parameters.

Built on top of `reservoir_computer.py` (your `reservoir_computer` class,
used **unmodified**). The Henrici departure is the class's
`henrici_departure()` method and the VPT is the class's
`valid_prediction_time()` method (threshold = 0.5·std of the true data).

## Files

| File | Purpose |
|---|---|
| `reservoir_computer.py` | Your reservoir computer class (unchanged) |
| `common.py` | Shared utilities: Lorenz pool, one-trial runner, npz savers |
| `pilot.py` | Small 12-trial check that the trend exists (ran first) |
| `exp1_a_sweep.py` | Henrici departure `a` = 0…10, n=200, default sr/alpha — 90 trials |
| `exp2_n_vs_a.py` | reservoir size n ∈ {100,200,400,800} × a ∈ {0,1,2,4,6} — 120 trials |
| `exp3_sr_vs_a.py` | spectral radius ∈ {1.5,3,4.78,7} × a ∈ {0,1,2,4,6} — 120 trials |
| `exp4_alpha_vs_a.py` | alpha ∈ {0.01,0.1,0.405,0.8,1} × a ∈ {0,1,2,4,6} — 150 trials |
| `exp5_n_sr_pair.py` | n ∈ {100,400} × sr ∈ {3,6} at a ∈ {0,2,6} — 72 trials |
| `run_all.py` | runs exp1…exp5 in order and combines the npz files |
| `make_plots.py` | regenerates all six PNG figures from the saved npz files |
| `make_summary.py` | prints/saves the per-experiment median table + Spearman rhos |

## Data

`data/lorenz_pool.npz` — 10 standardised Lorenz-63 trajectories
(70 000 steps each, dt = 0.01, RK45, rtol 1e-8, 5000-step burn-in,
StandardScaler per trajectory). **One shared pool is used by every
experiment**, so all comparisons are made on the same data (trial k of a
setting uses trajectory k mod 10). Regenerate with:

```
python -c "import common; common.generate_lorenz_pool(n_traj=10)"
```

## Results

`results/exp*.npz` — one file per experiment. Each contains, per trial:
`vpt`, `henrici` (Henrici departure of that reservoir),
`henrici_norm` (= henrici/n), the seeds, the trajectory index, the
echoed parameters (`a`, `n`, `spectral_radius`, `alpha`, `res_density`)
and a `metadata` key with the full experiment description (grid,
defaults, dates, data details). `results/all_experiments.npz` is the
combined file; `results/summary.txt` is the compact median table.

`plots/fig1…fig6.png` — the figures (all regenerated by `make_plots.py`).

## How to re-run everything

```
python run_all.py      # re-runs all experiments (~40 min on a laptop)
python make_plots.py   # re-draws all figures from results/*.npz
python make_summary.py # re-prints the summary table
```

## What was found (median VPT, 10/6 trials per setting)

The effect is a sharp cliff: for the normal reservoir (a = 0, Henrici = 0)
the median VPT is ~340 steps in every experiment, and any non-zero
Henrici departure drops it to ~5–120 steps. Spearman correlation between
Henrici departure and VPT is strongly negative in every experiment:

| experiment | Spearman rho (henrici vs VPT) |
|---|---|
| exp1 (a sweep) | −0.69 |
| exp2 (n × a) | −0.77 |
| exp3 (sr × a) | −0.17 |
| exp4 (alpha × a) | −0.74 |
| exp5 (n × sr × a) | −0.79 |
| all 552 trials pooled | −0.47 (henrici/n), −0.66 (raw, log-log) |

Per-experiment detail (median VPT vs a; Henrici of the normal reservoir
is exactly 0):

* **exp1:** a = 0, 0.5, 1 → VPT ≈ 341, 342, 335 (Henrici 0, 12.6, 26.3);
  a = 2, 3, 4, 6, 8, 10 → VPT ≈ 18.5, 10.5, 8.5, 13.5, 21.5, 13
  (Henrici ≈ 46–71).
* **exp2:** at a = 0, VPT ≈ 352/341/338/278 for n = 100/200/400/800;
  once a ≥ 1 the VPT collapses to ~7–118 at **every** n.
* **exp3:** at a = 0, VPT ≈ 344 for all spectral radii; for a ≥ 1 the VPT
  collapses (≈ 13–97) regardless of sr.
* **exp4:** at a = 0, VPT ≈ 338 for all alphas; for a ≥ 2 the VPT is
  ≈ 15–25 for all alphas.
* **exp5:** a = 0 → median VPT 340–350 across all (n, sr) cells;
  a = 2 → 2–29; a = 6 → 7–24.

Interpretation: in this setup the non-normal (upper-triangular) part of A
destroys the usable prediction horizon almost immediately — the effect is
robust to reservoir size, spectral radius and alpha, and the Henrici
departure itself is a good (monotonically decreasing) predictor of VPT.

## Reproducibility notes

* All randomness is seeded: the seed of every trial is stored in the npz
  files, and the Lorenz pool has a fixed seed base (1000 + i).
* Randomness per trial = (Win draw, ER graph + weights draw,
  upper-triangular perturbation draw, input noise) — all from the global
  numpy stream, seeded once per trial.
* VPT is measured on a 2000-step one-step-ahead rollout starting at step
  50000 of each trajectory, threshold = 0.5·std(true) (class default).
